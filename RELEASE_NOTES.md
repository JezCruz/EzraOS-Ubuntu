# EzraOS Ubuntu v2.1.0 Alpha

First public alpha release of **EzraOS for Ubuntu**, an offline AI-powered development and learning environment that runs directly on Ubuntu Linux.

EzraOS provides a terminal-based interface with multiple specialized AI modes powered locally through **llama.cpp**.

## Features

* Offline AI chat powered by llama.cpp
* Custom EzraOS terminal interface
* Persistent user name with first-time setup
* Name can be changed in Settings
* Mode-specific greetings and focused AI assistants
* General Chat mode
* Java Programming mode
* Python Programming mode
* SQL Learning mode
* Git and GitHub mode
* Linux mode
* Bible Study mode
* Streaming AI responses
* Separate conversation history per mode
* Automatic history trimming to reduce context errors
* Notes module
* Project repository scanner
* System information
* Background llama-server management
* Works locally after the AI model is downloaded

## Platform

This edition of EzraOS is designed for:

* Ubuntu Linux
* Ubuntu-based Linux distributions where compatible

Unlike the Android edition, this version runs directly in a Linux environment and does not require Termux.

## Requirements

* Ubuntu Linux
* Python 3
* llama.cpp / llama-server
* curl
* git
* Internet connection for initial installation and model download
* Sufficient storage for the selected AI model
* At least 4 GB physical RAM recommended

## Offline Usage

After EzraOS, its dependencies, and the AI model have been installed, the core AI features can run locally without an internet connection.

Internet access may still be required for external services such as GitHub operations, package installation, updates, or downloading additional models.

## Current Status

This is an **Alpha release** of EzraOS for Ubuntu.

Bugs, installation issues, hardware-specific problems, and compatibility issues may still occur.

EzraOS is an **OS-like AI development environment running on top of Ubuntu Linux**. It is not a standalone operating system and does not replace Ubuntu.
